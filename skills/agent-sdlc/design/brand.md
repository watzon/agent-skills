# Brand

Read when a product has no brand and you are at step 3 of the [design process](index.md). The brand brief comes before the logo, any mascot, and the foundations; each of those is checked against it.

## Inputs

- **Purpose:** what the product is for, who it serves, the one action. If missing, infer it from the request and state it in one line, or ask one question.
- **Name:** get it before any visual work: the name shapes the brand and the mark. If there is none, ask for one; a working name is fine, marked as such, and a rename redoes the logo.
- **Name constraint:** if the name cannot be drawn (an abstract word, a made-up word), write that down. The mark then comes from the product's own reference point, or from the letters, not from a picture of the word.

## Steps

1. **List the neighbors:** products the audience would compare this one with. Note what each looks and sounds like, so you know what to avoid matching. Study the real products (their sites, icons, and marks) if you can browse; otherwise work from memory. Label the list "studied" or "from memory".
2. **Draft 3 to 5 brand directions in words.** Each: a position in one sentence, three brand words, the voice in one line, and one reference from outside software (a material, a trade, a place). Any two directions differ in position, not just in adjectives.
3. **Choose one.** Write the reason, tied to the purpose and audience. Log each reject in the [drop log](index.md#drop-log), one line with why.
4. **Write the brief** (below). It is the reference every later design step is checked against.

The counts here (directions, brand words, anti-references) are house defaults with no source; change them with a reason.

## The brief

One page. Each line is a decision with its reason.

1. Purpose, audience, the one action.
2. Name, and what it suggests or constrains.
3. Position: the one sentence, and how it differs from the neighbors.
4. Three brand words, and two anti-references (what the brand refuses), each with a reason.
5. Voice: how the product talks, in one line. Detailed copy rules: [anti-slop/copy.md](../anti-slop/copy.md).
6. Personality: reserved or outgoing. This decides whether a mascot or a character mark is even a candidate.
7. Rejected directions, one line each.
8. What would change the call.

## What not to use as a reason

- Brand archetypes (hero, sage, rebel): prompts for drafting directions only.
- Statistics on how much color or a logo "raises recognition": any statistic in a brief needs a source.
- Trend reports: use them to check the work is not merely following a trend, never as a reason.
- Recognition figures from single studies: never quote a number.

Evidence status for each: [sources/design.md](../sources/design.md).

## Done when

- [ ] The purpose and a name (or a marked working name) are written down before visual work began.
- [ ] The neighbor list exists, labeled studied or from memory.
- [ ] 3 to 5 brand directions were drafted; one chosen with a reason; rejects logged.
- [ ] The brief has every numbered line above, each with a reason.
- [ ] No archetype or uncited statistic is given as a reason.
